# Sales Data Visualization

## Overview
This project analyzes a sales dataset using Python and data visualization techniques to identify business insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations
- Product Category Sales
- Region-wise Sales
- Monthly Sales Trend
- Sales by Sales Representative
- Payment Method Distribution
- Discount vs Sales Amount
- Customer Type Sales

## Conclusion
The visualizations helped identify sales trends, customer behavior, regional performance, and payment preferences, providing useful insights for business decision-making.
